## 目标

把 M8 冻结的米制深度预处理算子以工作流节点形式进画布：`Depth32F` 端口
域 + 相机米制源 + 五个确定性算子节点 + 有状态历史堆叠节点，用户可拖拽
组装完整策略输入管线并逐节点观察中间产物；同时移除 M9 的固定预览卡片
（被组合能力取代），保留米制通道与契约。

## 范围与非目标

范围：

- [DEC-020](../decisions/DEC-020-workflow-depth-domain.md)：Depth32F 端口
  语义、七节点目录、`IStatefulImageNode` 引擎串行在飞执行、米制帧源路由、
  缩略图 P99 显示、卡片移除。
- 节点数值语义复用 M8 冻结公式（双精度参考法 golden）。
- 引擎状态节点时序独立验证（乱序完成压力、跨代复位、去重）。

非目标：

- ONNX 推理与张量进程间交付（后续立项）。
- 米制帧的对齐/录制（POST-01）。
- 引擎 maxInFlight 通用有序化（仅状态节点图串行，非全局改动）。

- 目录追加次序契约（新条目必须在尾部，否则契约套件泛式构图破坏）。
- 引擎串行路径不得影响既有无状态图（回归面：契约套件 + 全量 ctest）。

## 测试与退出条件

  tsan；真机画布组装验收（用户）。
