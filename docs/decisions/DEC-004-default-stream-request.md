# DEC-004：默认流配置 848x480@30 RGB+Z16

> 状态：Accepted（暂定默认值转正；如需调整按决策流程变更）
> 日期：2026-09-23
> 负责人：Linductor-alkaid
> 冻结里程碑：M1
> 替代/被替代：无

## 背景与问题

viewer 启动需要固定一个初始流请求；档位下拉依赖设备能力枚举，在能力到达前必须有
稳定的默认值。

## 决策

默认 `StreamRequest` 为彩色/深度均 848x480@30fps（RGB8/Z16）。理由：848x480 是
D435 系列深度原生档位、30fps 为深度相机帧率上限档、CPU 转换开销适中（M1 软件转换）。

## 备选方案

- 640x480@30：兼容面更宽，但非深度原生比例优势档；作为键盘/下拉可选项存在。
- 1280x720@30：视觉更好，软件 jet/RGBA 转换 CPU 占用明显上升，留给后续优化。

## 影响与风险

- 能力枚举滞后于首帧：viewer 以默认请求启动，档位列表就绪后下拉自动选回 848x480。

## 验证方式

真机启动即以 848x480 出流（M1 验证记录截图）；下拉默认选中项即 848 x 480。
