# DEC-010：IMU 姿态融合算法选型（六轴 Mahony 显式互补滤波）

> 状态：Accepted
> 日期：2026-09-24
> 负责人：Linductor-alkaid
> 冻结里程碑：M3（M3-01 调研冻结）
> 替代/被替代：无

## 背景与问题

M3 要为 D435if 的加速度计/陀螺仪（ACCEL/GYRO，`RS2_FORMAT_MOTION_XYZ32F`）提供六轴
姿态融合：Core 输出姿态四元数，viewer 在固定世界坐标系 3D 视图中实时呈现相机位姿
（总计划 `SCOPE-07`）。`ImuFuser` 必须是 Core 纯逻辑，在采集 blocking worker 循环内
按样本推进、热路径无堆分配（`EXEC-06`），不得进入 EUI 渲染线程（`RULE-07`）。pinned
librealsense 的 IMU 出流速率为陀螺 200/400 Hz、加速度计 63/250 Hz
（`build/iva-debug/_deps/realsense2-src/src/ds/ds-motion-common.h:18-36`），即融合器
每秒最多被推进约 400 次。

需要决策的问题：在六轴（无磁力计）场景下，从互补滤波 / Mahony / Madgwick / 简化 EKF
四种候选中选定姿态融合算法，并给出可执行的数值验收方案。

六轴问题的物理边界（决策前必须明确，避免对不可观测量提出验收）：

- 加速度计仅能感知重力方向，提供 roll/pitch 两自由度参考；姿态绕重力轴的旋转（yaw）
  不可观测（Sabatini 2011 可观测性分析在仅有重力单一参考时的直接推论；
  [Sensors 11(10):9182](https://doi.org/10.3390/s111009182)）。
- 因此 yaw 漂移速率由陀螺 z 轴零偏决定，任何候选算法都无法消除，只能通过零偏估计
  缓解；长期 yaw 漂移属于传感器物理限制，须如实披露（M3 非目标已声明）。
- 设备级噪声/零偏参数可从 SDK 读取：`rs2_motion_device_intrinsic` 提供
  `noise_variances` / `bias_variances`（`include/librealsense2/h/rs_types.h:70-84`，
  经 `rs2_get_motion_intrinsics` 获取，`include/librealsense2/h/rs_sensor.h:468`）。

## 决策

选定 **Mahony 显式互补滤波**（Mahony et al. 2008,
[IEEE TAC 53(5)](https://doi.org/10.1109/TAC.2008.923738)：SO(3) 上的
explicit/passive complementary filter）作为 Core `ImuFuser` 的六轴姿态融合算法，
四元数实现，PI 反馈 + 陀螺零偏在线估计：

1. **状态**：单位四元数 `q`（传感器系→世界系，Z 轴向上；具体方向约定由 M3-03 契约
   文档锁定）+ 陀螺零偏估计 `b̂`（3 维，PI 积分项）。无其他状态。
2. **推进方式**：按样本推进——GYRO 样本执行四元数传播（`dt` 取相邻设备时间戳差，
   时间戳单调校验），ACCEL 样本提供重力方向修正项；实现层两个流按各自时间戳驱动的
   次序语义由 M3-05 以数值测试锁定。**不引入独立融合节拍**，`EXEC-06` 无需修订。
3. **重力参考门限**：`|‖a‖ − 1g| > 10%` 时跳过该样本的修正与零偏更新，仅做陀螺
   传播（线加速度/振动污染防护；门限期间 roll/pitch 由零偏估计兜底）。
4. **初值与复位**：首次有效 ACCEL 样本对齐 roll/pitch、yaw 置 0；`reset()` 幂等恢复
   构造初态。
5. **参数**：默认 `Kp = 1.0`、`Ki = 0.1`（构造参数可注入；原型实测该组合满足全部
   数值判据，见"验证方式"）。若 M3-08 真机复核表明默认增益需调整，仅改默认值，
   不构成对算法选择的推翻。
6. **输出与披露**：`ImuSnapshot`（姿态四元数 + 源频率统计 + 序号）经
   `LatestMailbox` 发布（`EXEC-06` 既有语义）；yaw 漂移为六轴物理限制，在用户文档
   与 viewer 中如实披露，不宣称绝对航向。
7. **边界**：纯逻辑、确定性、热路径无堆分配、公开头零第三方类型（`RULE-01`）；
   仅在采集 worker 内推进，不新建线程/队列（`RULE-02`/`RULE-03`/`RULE-07`）。

## 备选方案

对比维度按 M3-01 要求：漂移特性、计算量、参数敏感性、可测试性。

| 方案 | 六轴漂移特性 | 计算量（每陀螺样本） | 参数敏感性 | 可测试性 |
| --- | --- | --- | --- | --- |
| Euler 角互补滤波（固定 `alpha`） | roll/pitch 有界；yaw 漂移 = 全部零偏（无补偿）；Euler 表示存在万向节锁 | 最低（`alpha` 混合 + `atan2`，官方示例即此结构） | 单参数但收敛带宽与噪声抑制耦合，无法调零偏 | 简单，但 Euler 角与四元数契约不一致且存在奇异，需二次转换 |
| **Mahony 显式互补滤波（选定）** | roll/pitch 有界且零偏被估计补偿；yaw 漂移 ≈ `b_z`，Ki 使其优于无零偏估计（实测 60s 23.2° vs 28.3°） | 低（本机实测 49 ns/样本，双精度 `-O2`；与文献 Madgwick 同量级） | `Kp`/`Ki` 两参数，物理含义明确（比例修正带宽 / 零偏跟踪速率） | 纯函数、可注入初值与参数、有 Lyapunov 近全局稳定性理论（Mahony 2008） |
| Madgwick 梯度下降（IMU 模式） | roll/pitch 有界；IMU 模式无零偏估计状态，yaw 漂移 = 全部零偏 | 低（实测 65 ns/样本；文献声称每更新 109 次标量运算，Madgwick 2010 报告） | 单参数 `β = √(3/4)·ω̄_β`（陀螺误差量级） | 同为纯函数可测；零偏需外挂估计器，破坏"单算法可测"完整性 |
| 简化 EKF（状态 `[q, b]`） | 高斯假设下理论最优；yaw 可观测性同样缺失（仅重力参考） | 高（4×4 协方差传播 + 求逆，每样本数百至数千次浮点运算；未原型实测，属结构推断） | `Q`/`R` 协方差 6+ 参数，调参最敏感：Caruso 2021 十算法基准显示参数不当的误差与默认值相当 | 可测，但需额外覆盖矩阵数值稳定/发散边界，测试矩阵最大 |

未采用理由：

- **Euler 互补滤波**：pinned librealsense 官方示例
  （`examples/motion/rs-motion.cpp:112-191` 的 `rotation_estimator`，
  `alpha = 0.98`）即该方案——无零偏估计、Euler 表示在 pitch ≈ ±90° 奇异、轴映射
  逐轴手写。它只能作为"最简可行"参照，无法作为 3D 位姿视图的全姿态四元数源。
- **Madgwick**：本机同数据原型实测稳态精度与 Mahony 相当（60s 旋转序列 roll/pitch
  RMS 0.078° vs 0.118°，均远低于判据），但无在线零偏估计（yaw 漂移停留在 Ki=0 的
  水平：28.1° vs 23.2°）、重力参考门限期间 roll/pitch 无零偏兜底、收敛更慢
  （<0.5° 需 7.1s vs 2.6s）、每样本成本更高（65 ns vs 49 ns）。
- **简化 EKF**：Caruso et al. 2021
  （[Sensors 21(7):2543](https://doi.org/10.3390/s21072543)）对十种融合算法的基准：
  各算法在最优调参下无统计显著差异（绝对误差 3.8°–7.1°），参数选择起决定作用——
  EKF 的最优性优势在调参正确时也不成立，而其参数敏感性、实现复杂度与数值边界
  测试成本最高；对本里程碑"实时预览位姿可视化"用例收益不成比例（VIO/SLAM 为
  非目标，`POST-05`）。

## 影响与风险

- **影响范围**：`M3-03` 公共契约（`MotionSample`/`ImuSnapshot` 语义）、`M3-05`
  `ImuFuser` 实现、`M3-06`/`M3-07` 消费端与关闭回归；`EXEC-06` 维持不变；
  CHANGELOG 于 M3 退出时统一补条目。
- **风险与缓解**：
  1. *yaw 漂移物理限制*：`b_z` 不可观，长时间使用 yaw 以设备陀螺 z 零偏速率漂移
     （本机原型注入 0.5°/s 时 60s 漂移 23.2°）。缓解：文档/UI 如实披露 + 3D 视图
     重置（`M3-06` 已含视图重置）；决策本身不宣称绝对航向。
  2. *线加速度污染*：1g 门限在高动态运动中可能较长时间关闭修正，roll/pitch 依赖
     零偏估计维持。预览类用例运动幅度有限，静态与突发扰动场景均已实测（见验证
     方式 5）；剧烈甩动场景超出现用例，风险接受。
  3. *真机噪声参数差异*：原型采用文献典型噪声（σ_g = 0.002 rad/s、σ_a = 0.02 m/s²），
     真机噪声/零偏以 `rs2_motion_intrinsics` 为准（M3-04 读取）。M3-08 真机冒烟
     复核默认 `Kp`/`Ki` 适配性；不适配时仅调参数，不改算法。
  4. *精度声明边界*：数值判据为合成数据（固定种子）实测；未宣称真机精度指标，
     真机记录按 M3-08 规范留存。
- **台账**：不引入新第三方依赖，不触及 Executor 能力边界，无台账新增项。

## 验证方式

M3-05 以纯逻辑单测（`unit` 标签）实现下列可执行验收；合成数据生成器使用固定种子
RNG、已知真值四元数轨迹。默认生成器参数：`dt_gyro = 1/400 s`、`dt_accel = 1/250 s`、
σ_g = 0.002 rad/s、σ_a = 0.02 m/s²、注入零偏 `b = [0.3, −0.2, 0.5]°/s`（可按
motion intrinsics 换算值替换）。阈值括号内为 2026-09-24 调研原型实测值
（g++ 13.3.0 `-O2`、双精度、本机 Linux；一次性脚本不入库，证据记于 M3 验证记录）：

1. **静态重力对齐收敛**：真值 30°/20° 双轴倾斜（初始 roll/pitch 误差 35.9°），
   默认参数下 ≤4s 内 roll/pitch 误差 <0.5°（实测 2.58s）。
2. **已知旋转序列跟踪**：60s 多轴正弦序列（roll ±30°@0.2Hz、pitch ±20°@0.35Hz、
   yaw 5°/s + ±15°@0.1Hz）：roll/pitch RMS ≤0.5°（实测 0.118°），峰值 ≤2°
   （实测 0.364°）。
3. **yaw 漂移披露性验收**：同序列 60s 末 yaw 误差 ≤ `|b_z|·60s`（实测 23.2°，
   物理上界 30°），且 Ki 开启误差 < Ki 关闭误差（实测 23.2° < 28.3°）。
4. **零偏估计**：静态 60s 后 `|b̂_x|`、`|b̂_y|` 残差 ≤0.2°/s（实测 0.061/0.111）；
   `b_z` 残差仅记录不设阈值（不可观测，实测 0.177）。
5. **线加速度扰动**：叠加 ±2 m/s² 平移加速度突发（5s 通/5s 断），门限开启时
   roll/pitch RMS ≤0.5°（实测 0.118°）、峰值 ≤2°（实测 0.364°）。
6. **复位幂等**：`reset()` 后以相同输入序列推进，输出与全新构造实例逐位一致；
   连续两次 `reset()` 结果一致。
7. **确定性**：固定种子场景在 debug/asan/ubsan/tsan 预设下输出一致、全部通过
   （`DOD-03`）。
8. **每样本开销**：≤1 µs/样本（实测 49.3 ns，≥20 倍裕量；400 Hz 下占单样本 2500 µs
   预算的 0.002%），且热路径无堆分配（与 `EXEC-06` 一致，实现以测试断言）。

真机验收：`M3-08` 按 D435if 冒烟记录 IMU 出流频率、姿态跟随与 restream 后恢复，
不对真机提出上表数值阈值。
